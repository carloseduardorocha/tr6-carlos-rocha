Ferramentas de qualidade de software

Git

Sistema de controle de versões. Registra cada mudança do projeto, permite trabalhar em branches e voltar a versões anteriores.

SonarQube

Faz análise estática do código e aponta bugs, vulnerabilidades, duplicações e código difícil de manter.

GitHub Actions

Ferramenta de integração contínua. Roda validações e testes a cada envio de código e automatiza a publicação.

Ferramentas de teste

JUnit

Framework de testes unitários para Java. Verifica se cada parte do código funciona isoladamente.

Selenium

Automatiza o navegador para testar aplicações web como se fosse um usuário real.
